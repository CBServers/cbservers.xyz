Features

Everything between you and the game

The launcher handles the setup, updates and housekeeping so the only button you need is Play.

Your files or ours

Point it at a Steam or existing install, or download the game straight from our CDN.

Always current

The launcher, every client and the game files update automatically. Hash-verified, resumable downloads.

Fast verification

Something broke? Verify checks every file and replaces only what changed, in seconds rather than a reinstall.

Manage content

Pick which campaign, multiplayer, zombies and DLC pieces you keep installed. Deselect to free the space.

Mods and Workshop

Browse the Steam Workshop for Black Ops 3 and hosted catalogs for other games. Custom maps install with one click.

Friends and invites

See what friends are playing and invite them into your match. Link Discord for rich presence, or use a launcher account with no Discord at all.

Server browser

Every game page has a live server list with map, mode, players and ping, so you can join without opening the game first.

Fixes the boring parts

Installs the Visual C++ and DirectX redistributables with one prompt, keeps a shared GUID across clients, and opens straight from cbservers:// links.

Play together

Friends, invites, rooms

Presence and invites work across every client the launcher runs, whether or not the game itself has a friends list.

  • Live presenceMap, mode, server and player count for every friend in a game, in the launcher and on Discord.
  • One-click invitesInvite a friend and they land in your match, even if the game was not open yet. Friends of friends can join too.
  • Community roomsA looking-for-group board and chat per game, plus direct messages, without leaving the launcher.

Getting started

Four steps to Play

Full install guide →

Download

Grab cb-launcher.exe and run it from any folder. There is no installer, and it keeps itself updated.

Pick a game

Open the Library and choose a title. Games you already have installed are detected automatically.

Set up

Use an existing install, or download the game and choose which content to include.

Play

Hit Play, pick a mode if the game has more than one, and you are in. Verify is one click if anything breaks.
